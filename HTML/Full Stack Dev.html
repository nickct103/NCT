HTML

HTML stands for Hypertext Markup Language. This language allows coders or developers to build Webpages. In turn, these webpages will be interlinked together to create a website with multiple webpages. In this section I will go over the basics of HTML and what each element is used for.

Tags

Tags are the building block of the HTML structure and are used in a variety of different ways depending on the webpage that is being created.There are two different types of tags: Paired Tags and Self Closing Tags.

Paired Tags

Paired tags are two sets of similar tags that are nicknamed opening and closing tags. The difference between an opening and closing tag is that the closing tag will have a "/" before the tag.
Examples:

  • html-/html- Start of an HTML document
  • head-/head- What will display on the tab or heading of a document. Usually consists of another Paired Tag of title-/title.
  • body-/body- The body of the text of where the elements will go.
  • headings (h1, h2, h3, h4, h5, h6)- Headings are used to create different sizes of text with h1 being the largest and h6 being the smallest.
  • p-/p- Paragraph format in which you can type large bodies of text.

Self Closing Tags

  • br- Line Breaks are when you can start a brand new line
  • hr- horizontal line- Example is the line underneath the caption under the heading showing "My Learning."
  • img- adding images

Boilerplate

The Boilerplate is the foundation of any HTML webpage. It consists of an opening and closing html tag, opening and closing title tag and an opening and closing body tag. Below is an example of the Boilerplate when you type "html:5" into the Code Editor.

Attributes

Attributes are items that are added to the opening tag to add a diiferent structure to the code that you are writing. Just like in img, we need an attribute that will show us what the source (src) would be.

The src is the location of an image that is being used and alt means alternate name in the offchance that the image doesn't load.
