Chapter 1

Summary:

  • HTML pages are text documents.
  • HTML uses tags (characters that sit inside angled brackets) to give th information they surround special meaning.
  • Tags usually come in pairs. The opening tag denotes the start of piece of content; the closing tag denotes the end.
  • Tags are often referred to as elements.
  • Opening tags can carry attributes, Which tell us more about the content of that element.
  • Attributes require a name and a value
  • To Learn HTML you need to know what tags are avalable for you to use, what they do, and where they can go.

Chapter 2-Text

HTML has six levels of headings ranging from h1 which is the biggest heading and h6 being the smallest. These are used to differentiate between sections.

A paragraph consists of one or more sentences that form a self-contained unit of disocurse. The start of a paragraph is indicated by a new line.

Text is easier to understand when it is split up into units of text. For example, a book may have chapters. Chapters can have Sub headings. Under each heading there will be one or more paragraphs.

Chapter 5-Images

There are many reasons why you might want to add an image to a webpage: you might want to inclide a lofo, photograph, illustration, diagram, or chart.

There are several things to consider when selecting and preparing images for your site, but taking time to get them right will make it look more attractive and professional. In this chapter you will learn how to:

  • Include an image in your web pages using HTML
  • Pick which image format to use
  • Show an image at the right size
  • Optimize an image for use on the web to make pages load faster.

To add an image into the page you will need to use an img element.

For the image above there are multiple attributes attached to the img tag:

  • src stands for source. In this case the source of the image. In this case it is in the images folder as a part of my coding venture.
  • alt provides a text description of the image which describes the image if someone cannot see it on the webpage
  • title is an attribute with the img element to provide additional information about the image. Most browsers will display the content of this attribute ina tooltip when the user hovers over the image.
  • height specifies the height of teh image in pixels.
  • width specifies the width of the image in pixels.

Where To Place Images in your code

  1. Before a paragraph- The paragraph starts on a new line after the image.
  2. Inside the start of a paragraph
  3. In the middle of the paragraph

Where you place the image in the code is important because browsers show HTML elements in one of two ways: Block elements always appear on a new line. Examples of block elements include the h1 and p tags. Inline elements sit within a block level element and do not start on a new line. Examples of inline elements include the b, em, i and img elements. As seen with the images above, the images can be placed within the same lines of other elements and they won't affect whether or not another line will be created.
